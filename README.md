# Águajá Gelajá — Catálogo digital

Site estático responsivo com catálogo por categorias, busca, ordenação, carrinho e envio de pedidos para o WhatsApp.

## Como visualizar
Abra `index.html` em um navegador. Para desenvolvimento local, recomenda-se iniciar um servidor estático simples na pasta do projeto.

## Como publicar gratuitamente no GitHub Pages
1. Envie todos os arquivos e pastas deste projeto para a raiz do repositório `aguaja-gelaja-catalogo`.
2. No GitHub, entre em **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`, depois salve.
5. Aguarde o GitHub Pages publicar o site e mostrar o endereço.

## Produtos e ajustes
- Os produtos e preços ficam em `assets/products.json`.
- O visual fica em `assets/style.css`.
- A busca, categorias, carrinho e pedido WhatsApp ficam em `assets/app.js`.
- Para usar as logos oficiais, coloque os arquivos em `imagens/logo-aguaja.png` e `imagens/logo-gelaja.png`.
- As imagens de produtos ainda são ícones ilustrativos; substitua por fotos reais quando disponíveis.
